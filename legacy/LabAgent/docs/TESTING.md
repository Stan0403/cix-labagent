# 验证与验收

## 已实现的可重复验证方式

```powershell
.\scripts\test.ps1
.\.venv\Scripts\ruff.exe check .
```

测试输出保存在 `test-results/junit.xml`，覆盖率输出到终端。它验证软件规则和适配器契约，不代替模型/硬件实测。

| 验证层 | 方法 | 能证明什么 | 不能证明什么 |
|---|---|---|---|
| 状态机 | 构造事件、自动断言状态 | 跳步阻断、重测、时效、暂停逻辑 | 现场已经断电 |
| HTTP/存储 | FastAPI TestClient、SQLite 实际文件 | API 行为、事务、并发版本校验、报告 | 云服务和实机可用 |
| 模型接口 | MockTransport 与受控模型响应 | 请求格式、解析、超时/错误边界、工具约束 | 大模型真实回答质量 |
| 图片集成 | 受控识别返回输入流程 | OCR 结果能通过规则进入候选记录 | 检测和 OCR 准确率 |
| 回放 | 三个 JSON 剧本，独立会话 | 端到端流程和异常分支 | 真实传感器测量 |
| 实际感知评估 | 人工标注图片 + 实际配置的模型 | 数据集上的器材存在性和电压读数指标 | 电气安全、板上 NPU 帧率 |

## 无设备时的验收步骤

1. 新建真实会话，不确认 SOP 就点下一步，必须阻断且日志显示拒绝原因。
2. 运行“完整流程”回放：应完成九步、保存 1.25 V，但来源必须为 replay，报告必须写非真实测量。
3. 运行“缺少万用表”回放：停在器材检查，不能进入测量。
4. 运行“未确认断电”回放：停在断电确认，不允许确认连接或上电。
5. 问当前进度/为什么阻塞：不改变步骤。
6. 完成回放后选择重新测量：旧记录仍在并标记被替代；新记录不能覆盖旧记录。
7. 不配置视觉服务时点识别：必须显示未配置，不出现假器材或假读数。
8. 刷新浏览器：实验与日志仍在。

## 真实图片标注评估

准备一个目录，放图片和 `manifest.json`。这里的电压只是格式示例，必须替换为人工标注的真实值：

```json
[
  {"image":"frame01.jpg","objects":["sensor","multimeter","breadboard","wires"],
   "roi":[0.4,0.3,0.2,0.15],"voltage":1.25,"tolerance":0.01},
  {"image":"frame02.jpg","objects":["sensor","breadboard","wires"]}
]
```

配置实际模型之后执行：

```powershell
.\.venv\Scripts\python.exe scripts\evaluate.py your-dataset\manifest.json
```

使用 VLM 时需核对服务地址，并明确附加 `--allow-remote` 才会发送数据。
结果默认写入 `test-results/perception.json`，指标不存在有效样本时为 null，不捏造 100%。
器材指标是**逐帧类别存在性** precision/recall，不是检测框 mAP。OCR 按标注容差和最低置信度计算命中率。
报告延迟是执行本次配置的模型耗时，不得把开发电脑的结果当成 P1/NPU 的实测值。

## 可选浏览器检查

`scripts/browser_smoke.cjs` 使用 Node.js 20+ 和 Playwright，针对已启动的本机服务，检查新建、阻断、人工确认、进度问答、刷新持久化、回放、导出、重测及手机布局。
这是开发测试工具，运行 LabAgent 本身不需要 Node 或 Playwright。可通过 `LABAGENT_PLAYWRIGHT_MODULE` 指定已安装模块路径，`LABAGENT_CHROME_PATH` 指定浏览器。

如果执行环境禁止本机回环网络，可设置 `LABAGENT_TEST_BRIDGE=1`，脚本会通过标准输入/输出连接**真实 FastAPI TestClient 和 SQLite**，只替换 socket 传输，不模拟业务接口或结果。
这能测试浏览器行为与前后端集成，但不能证明浏览器到 Uvicorn 的真实网络部署已通过。

## 设备到位后必须补的测试

- 确认真实传感器型号、引脚、电压范围，教师审核并修订 SOP。
- 摄像头固定机位、照明、显示屏 ROI、小数点与单位可见性。
- 器材检测的遮挡、漏检、手部干扰、背景变化测试。
- 仪表多种量程与异常显示（OL、负号、单位不可见）的拒绝率。
- 串口 ADC 标定，读数与独立万用表对照，不能用同一个数据源“自证正确”。
- 配置真实模型后测试工具调用、上下文问答、超时与断网。
- 在 P1 上测内存、CPU/GPU/NPU 实际后端、时延、温度和长时间运行。
- 连续三次完整实机实验并保留原始日志；安全阻断由规则测试和现场复核共同确认。

## 当前明确不包含

尚未取得设备/权重/API 时，不能验证真实识别效果或云端服务；没有 CIX NPU SDK/模型转换产物；没有未指定 MCU 的固件、继电器控制或电气安全认证。上述事项不是留空 API Key 就能自动完成的工作。
