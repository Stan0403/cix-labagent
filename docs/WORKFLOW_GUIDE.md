# 自动检查工作流

本版基于 O6 正在运行的 LabAgent-demo 源码修改，沿用 Qwen3-VL-4B GGUF 视觉服务。固定规则决定每一步调用什么工具，不调用 LLM 来选择动作。

## 使用

O6 浏览器打开 http://127.0.0.1:8001，Ctrl+F5 刷新。审核实验计划后开始，允许相机。现有电池实验会话也会按步骤内容匹配检查规则。

| 阶段 | 自动行为 | 操作人员需要做什么 |
|---|---|---|
| 阅读要求 | 审核计划后记录阅读确认 | 核对实验文档与现场要求 |
| 器材 | VLM 识别、自动勾选和标框，缺少时复查 | 放齐器材，纠正误判，最终确认提交 |
| 仪表设置 | Qwen3-VL 检查 COM、V/Ω 插孔、直流档；程序校验量程是否覆盖计划范围 | 正确设置仪表，让插孔文字、旋钮指向和档位入镜 |
| 表笔接触 | 检查红正黑负及金属尖端是否短接 | 让两极、金属尖端和接触位置入镜，按提示调整 |
| 读数 | 自动定位、裁剪并连续读取 | 保持屏幕清晰、接触稳定 |
| 保存 | 两张不同画面的读数相差不超过 0.02 V 后，自动记录并保存最新值 | 可暂停自动检查后人工核对或修正 |
| 收尾 | VLM 检查两支表笔已移开、仪表已关闭 | 实际移开表笔，关闭仪表，让旋钮 OFF 指向入镜 |
| 报告 | 自动完成，保留图片引用、原始输出与核验方式 | 查看或导出报告 |

自动检查面板按项目显示“通过 / 未满足 / 待看清”。全部条件明确通过后才推进；不知道不等于通过。每轮响应完成后约 8 秒重拍，模型忙时等待重试，不并发堆积请求。

## 人工接管与恢复

点击“暂停自动检查，改为人工核对 / 修正”后，可使用人工确认和候选修正。点击“恢复自动指导”继续。物理操作发生变化时使用“现场变化 / 重新核对”，清除对应旧检查与量程证据。

模型连续三次读取不明确、或连续三次请求失败会暂停。复核后勾选现场确认并恢复，也可以人工读取。

## 数据含义与范围

- 自动检查保留 VLM 原始输出、检查项、拍摄时间、图片引用和后端名称。未知、遮挡、格式错误不能自动通过。
- 自动测量来源为 `vision_workflow`，人工核对候选为 `vision_confirmed`；软件演练始终为 `replay`。报告不把自动检查写成人工确认。
- 自动稳定性需要两张不同图像、至少相隔一秒、相同已核验量程、读数差不超过 0.02 V。两次结果都在已审核范围内才可能记录；不会只凭一次识别自动保存。
- 稳定性不等于准确度，系统不验证电池容量、仪表校准或实际导通。
- 当前自动接触与收尾适配单节电池的直流电压实验。其他文档仅在有对应规则时自动检查；不支持的操作明确保留人工核对。
- 需要相机实际拍到插孔、旋钮、两端接触或 OFF 指向；仅看见一个数字、空白屏幕或电线不能证明对应操作完成。
