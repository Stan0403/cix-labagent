# 实验切换、刷新与删除

同一块开发板一次运行一个实验。新建实验会在同一事务内暂停所有旧的运行会话；恢复历史实验时会暂停其他运行会话。暂停保留已有测量、图像引用、对话、步骤与过程记录，并追加暂停原因。旧请求绑定原会话及版本，切换后返回的模型决定或视觉结果不能继续推进旧实验。

刷新网页或点击历史实验，只打开记录并暂停自动指导。需要继续实验时，在任务卡点击“恢复”，核对现场后继续。服务重启同样暂停此前运行的会话；已完成会话保持完成状态。页面切换会停止原摄像头、定时任务和浏览器请求，历史不会被隐式自动运行。

历史列表每项显示状态和建立时间，并有“删除”入口。删除前明确确认；确认后仅删除指定会话、其中测量、对话、事件和 Agent 行动记录。删除当前实验后回到空白页，不自动运行其他实验；其他页删除了当前实验时，轮询会停止当前页面的任务。共享实验计划和图片资源保留，防止影响其他会话。部署过程不批量删除已有实验。

接口：

- `POST /api/sessions`：建立实验并暂停其他运行会话。
- `POST /api/sessions/{id}/open`：打开历史；可传 `previous_session_id` 暂停刚离开的会话。
- `DELETE /api/sessions/{id}`：正文必须包含 `confirmed: true` 和当前 `expected_revision`；缺少确认或版本过期不会删除。
- 既有恢复接口仍是 `POST /api/sessions/{id}/actions`，`kind=resume`，`confirmed=true`。

验证：`pytest tests/test_session_lifecycle.py` 检查记录保留、并发启动、重启、确认删除与迟到的模型结果；`scripts/browser_task_smoke.py --output <独立目录>` 检查真实页面的新建、刷新、历史查看、取消/确认删除及删除当前实验。使用独立测试数据和明确标记的模型 fixture，不操作正式实验。
