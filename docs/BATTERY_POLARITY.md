# 电池极性合并到读数环节

电池正向电压实验不再调用 `battery_contact` 或 `battery_cleanup` 大模型视觉检查。操作人员按说明保持红正黑负，摄像头读取万用表显示屏；负数提示检查连接，正数经两次采集稳定性核验与计划范围检查后记录。保存后显示约5秒“请移开表笔并关闭万用表”，随后继续生成报告，无需收尾拍照或确认。

- 负数（包括负零）与零值保留原始候选、图片及原因，标记为拒绝，不计入样本、不取绝对值。调整后需要重新取得两张独立正数画面；反接前的正数不能与调整后的正数拼接成一组。
- 两次读数相差不超过0.02 V、采集间隔至少1秒，且量程相同、证据未过期，才自动记录。两次都是1.34 V、图片像素完全一致也可以通过，无需改变姿势或晃动表笔。
- 浏览器每次等到摄像头的新视频帧后截取图像，生成独立采集编号。编号随普通读表或Agent执行请求传递；同一编号重复提交会拒绝，不算第二次采集。静态文件上传不生成摄像头采集编号，重复使用同一上传图片仍不能当两次独立现场采集。
- 图像按内容摘要保存，两次内容相同可以引用同一个图片文件；候选记录仍保留两个不同采集编号与时间。报告也用相同的采集规则核验，不再仅凭图像摘要不同来判断独立性。
- 新计划把电池接触操作说明合并到测量步骤。已有会话的原计划、步骤编号、事件与测量保留；旧的接触关卡在推进时转入读数核验，不伪造人工确认或视觉通过事实。
- 报告单独说明极性或零值导致的候选拒绝，不将它们写成人工拒绝或正式测量结果。
- 新计划移除收尾检查步骤，旧会话保留原计划和事件编号但推进时略过收尾视觉检查，不写入“已移开”或“已关闭”的假确认。收尾提示截止时间保存在会话中，刷新或重复保存不会重置计时；暂停状态优先，重测会清除旧提示。

测量定义的 `polarity_check` 可取 `auto`、`positive`、`signed`。默认 `auto` 对器材清单含电池的直流电压实验启用正值要求；需要保留反向电压的实验应明确使用 `signed`。非电池的通用电压测量保持有符号读数。

本规则依赖事先核对的 COM、V/Ω 插孔和直流档位，以及 OCR 对符号的识别。沿用现有负号与小数点图像核验；不能把正电压解释为摄像头已经证明了端子身份、接触位置或无短接。电池夹持、表笔分离等操作要求仍保留。
