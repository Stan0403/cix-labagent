# 比赛演示与使用说明

## 开始前

O6 浏览器打开 **http://127.0.0.1:8001**，点右上角“运行状态”，确认工作台、本地对话、NPU 语音、本地视觉均就绪。接入 O6 的摄像头和麦克风，并允许浏览器使用它们。

准备单节 1.5 V 干电池、数字万用表、红黑表笔。相机固定，万用表屏幕保持清晰，避免反光。以仪表实际标记核对直流 2 V 或 20 V 档、COM 与 V/Ω 插孔。

## 建议演示顺序

1. **先展示文档驱动。** 上传 `knowledge/battery_voltage.md`，或复制其中实验要求到文本框，点击“读取并拆解流程”。展开计划，展示文档行号、器材、测量要求与步骤。平台补充步骤会单独标明。
2. **审核后启动。** 查看原文，确认步骤和实物一致，勾选审核并开始真实实验。也可直接使用已提供的 1.5 V 电池示例。
3. **展示自动器材核验。** 进入器材阶段后允许相机，Agent 自动采集画面并调用本地 VLM，自动勾选识别到的器材并标框。可以先不放万用表，观察缺失提示；放回镜头后等待下一次观察。修正误识别，再勾选现场确认并提交器材确认。模型处理中请等待，不要反复点击。
4. **展示现场指导。** 核对插孔和直流量程，勾选现场确认。红表笔接正极、黑表笔接负极，避免短接，显示稳定后确认本步。
5. **展示自动读表。** 进入测量阶段后 Agent 自动拍摄，自动定位并裁剪显示屏，再调用 O6 上的 VLM 读取候选，无需手动框选。对照候选图片核对或修正，再勾选现场确认并确认候选；此时才形成测量。
6. **展示上下文问答。** 问“现在做到哪一步了？”“为什么还不能进入下一步？”“为什么使用直流电压档？”；也可录音转写后发送。进度类回答直接读取状态，复杂解释调用本地模型。
7. **展示可恢复异常。** 可以拒绝一次候选并重新拍照；也可“暂停指导”，再由现场人员确认恢复。不要为展示异常真的短接或使用错误电流接法。
8. **保存、收尾、报告。** 确认保存读数，移开表笔并关闭万用表，完成实验，导出报告和测量表。展示图像候选、模型原始值、人工修正和正式测量的关联。

## 给评委看的 Agent 行为

界面左侧同时展示当前目标、尚未满足的条件、下一步建议和工具入口。Agent 根据状态自动选择器材观察、读屏或推进；等待物理确认时停止自动操作。日志保留“观察→规则判断→操作→反馈”。缺少器材时等待，补齐后继续；读数未核对时不进入保存；无法识别时重拍或人工录入；连续三次不明确会暂停并提示教师介入。

文档提取、现场感知、状态记忆、规则和模型共同构成流程；涉及实际物理操作的确认由现场人员完成。

## 文档导入提示

编号文档建议格式：

```text
实验名称
实验器材：器材一、器材二
实验步骤
1. 第一项操作。
2. 第二项操作。
3. 读取测量值。
4. 保存结果并收尾。
注意事项
实际操作约束与需要确认的条件。
```

没有编号时可选择本地模型拆解。模型返回操作建议，仍需要审核。其他实验的测量单位和范围不明确时，先在计划中填写；没有对应自动感知适配器时使用人工核对和录入。

## 常见情况

- **没有候选数值：** 调整光照和角度，使万用表屏幕占画面足够大小，确保小数点和负号可见，等待自动重拍或点击重新观察；不要从模糊画面猜数。
- **候选过期：** 重新拍照。当前有效期为 15 分钟，防止把旧图当成当前状态。
- **现场操作确认过期或变化：** 使用“现场变化/重新核对”，确认恢复后重走必要检查。
- **低置信度连续失败暂停：** 请现场人员复核，可调整拍摄后恢复或人工读取。
- **麦克风/相机不可用：** 在 O6 的浏览器使用 `127.0.0.1` 地址，检查系统和网站权限。
- **端电压为负：** 核对极性与原图负号。保留真实符号，不能自动改成正数。
- **报告还没完成：** 先核对保存测量，再确认收尾，最后完成报告步骤。

电池端电压不直接等于剩余电量或容量；当前演示不包含容量诊断。
